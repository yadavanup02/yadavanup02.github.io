# Dr. Anup Yadav - personal academic website

Source for [yadavanup02.github.io](https://yadavanup02.github.io), the personal academic website of Dr. Anup Yadav.

The site is intentionally lightweight: plain HTML and CSS with no build step or external dependencies. GitHub Pages publishes `index.html` from the `main` branch.

## Update the site

Edit `index.html` for content and `style.css` for its design. Commit and push the changes to `main`; GitHub Pages will publish the update automatically.
